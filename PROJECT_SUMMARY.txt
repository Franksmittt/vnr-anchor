1. WHERE THE PROJECT IS NOW
================================================================================

This repository is the current VNR Professional Accountants marketing and lead
generation website. It presents VNR as a Centurion-headquartered accounting,
tax, compliance, and wealth-structuring partner serving clients across South
Africa.

Current implementation highlights:
- Next.js App Router application with 40 implemented app pages:
  - 15 static/support pages
  - 8 service detail pages
  - 17 insight article pages
- Homepage, services/pricing, insights, contact, Anchor Wealth, expat guide,
  local Centurion/Pretoria landing page, legal pages, and internal email
  signature generator are implemented.
- Services/pricing page uses the 2026 price list from data/pricing-data.ts with
  search, category filtering, VAT-inclusive pricing, "FREE", and quote labels.
- Service and insight pages are generated from structured data files.
- SEO foundations are in place: metadata helpers, canonical production domain,
  dynamic sitemap, environment-aware robots, structured data, breadcrumbs, and
  noindex directives for legal/internal/conversion pages where appropriate.
- Middleware handles lowercase/trailing-slash normalization, selected legacy
  redirects, canonical host redirect from www.vnr.co.za to vnr.co.za, one 410
  deprecated path, and baseline security headers.
- Contact form posts to app/api/contact/route.ts, validates required fields,
  tracks successful submissions, and redirects to /thank-you. The API currently
  acknowledges submissions only; no email, CRM, or database delivery is wired in
  from the visible code.
- Analytics hooks are GA4-ready when NEXT_PUBLIC_GA_MEASUREMENT_ID is provided.
  Current tracked interactions include WhatsApp, phone, email, and form submit.
- Automated SEO regression coverage exists through Playwright and a GitHub
  Actions SEO gate.

Known handover notes:
- The live/contact delivery destination should be confirmed before production
  launch because the current contact API does not persist or forward enquiries.
- Deployment operations still need to be completed outside code: domain/DNS,
  SSL, production environment variables, Google Search Console verification, and
  sitemap submission.
- The legacy redirect map still includes /who-we-are -> /team, but no /team page
  exists in the current app tree. Review that redirect before launch if legacy
  traffic is expected.

Technical endpoints and generated files:
- /api/contact
  POST endpoint for contact form submissions. Validates fullName, email, and
  message, then returns JSON success or validation errors.

  Generated by app/sitemap.ts. Includes core static routes, all service detail

5. TECHNICAL STATUS
================================================================================

Production/domain:
- Canonical production domain is locked in lib/site.ts as https://vnr.co.za.
- Root metadata uses SITE_URL as metadataBase.
- Middleware redirects www.vnr.co.za to vnr.co.za.

SEO:
- Metadata helper functions live in lib/seo.ts.
- Organization, service, article, FAQ, breadcrumb, and person schema helpers are
  available and used across key templates.
- Service and insight pages generate metadata dynamically from data files.
- Sitemap includes public core, service, and insight pages.
- Robots can block non-production environments and reference the production
  sitemap.

Conversion and tracking:
- Contact form submits to /api/contact and redirects to /thank-you on success.
- GA4 loads when NEXT_PUBLIC_GA_MEASUREMENT_ID is set.
- Tracking helper lives in lib/tracking.ts.
- WhatsApp floating action button and contact links include event tracking hooks.

Quality gates:
- npm run build builds the Next.js app.
- npm run test:seo runs Playwright SEO regression tests.
- .github/workflows/seo-gates.yml runs the SEO gate in CI.
